## Description
A retro Windows 98/2000-style desktop, entirely re-skinned in green-on-black. Multiple overlapping "windows" are open simultaneously: a "Program Console" showing obfuscated/minified JavaScript source, a "Neural Network" panel with a glowing plexus/node-graph visualization, a real-estate "Secret Deals" listing with a photo of a villa, a "Bitcoin Miner" panel with a live wallet balance, hashrate table, and mining-rig icon, and a "Password Cracker" panel showing a cracked password result. A taskbar runs along the bottom with a Start button and icons for each open app (Bitcoin Miner, Password Cracker, Secret Deals, Program Console).

## Recreation Prompt
A retro late-1990s desktop operating system UI, entirely monochrome bright green (#00ff41-ish) on pure black, styled like classic Windows 98 chrome (thin beveled borders, minimize/maximize/close boxes, title bars) but re-skinned into a hacker terminal palette. Show 4-5 overlapping draggable windows: a code console with obfuscated JavaScript, a neural-network node-graph visualization with glowing connected dots, a cryptocurrency miner dashboard with a wallet balance and scrolling hashrate log table, and a password-cracker window with a revealed password and success message. Add a faint green world-map or grid texture as the desktop wallpaper. Include a bottom taskbar with a Start button and app icons. CRT scanline overlay, slight glow/bloom on the text, monospace pixel font throughout.

## Site Application
Good reference for a playful "hacker desktop" landing page or an Easter-egg `/desktop` route — draggable/overlapping fake windows as a portfolio-piece showcase, or as an animated hero background (windows opening/typing in on load) behind the real nav and content.
