Center-left is a "redacted" ID card with a halftone portrait photo, name "SPIRE K", ID numbers, and class/status codes. Right-side panels list hacking-adventure-game-style action menus ("HACK SYSTEM.", "LOAD SHELL.", "MALWARE UPLOAD", "ERASE TRACE>"). Panel borders are built from ASCII/pixel-art line-art rather than clean rectangles.
