## Description
A classic Windows 95/98-style modal dialog box (gray beveled chrome, title bar with an X close button) titled "Loading 2026...". Inside, a green-on-black terminal-style progress bar sits at 1%, below it reads "ESTIMATED TIME REMAINING: UNKNOWN", with visible horizontal glitch/scan artifacts across the dialog body, and a gray "CANCEL" button at the bottom right.

## Recreation Prompt
A pixel-perfect recreation of a classic Windows 95/98 dialog box: light-gray 3D-beveled window chrome, a title bar reading "Loading 2026..." with a small close (X) button, set against a plain white backdrop. Inside the dialog's content area is a black terminal panel with green monospace text and a horizontal progress bar filled to 1%, dense vertical green scanline/static texture behind the bar, and the line "ESTIMATED TIME REMAINING: UNKNOWN" below it. A raised gray "CANCEL" button sits bottom-right of the dialog. Subtle glitch smear/ghosting on some text lines to suggest a corrupted, stuck loading state.

Perfect literal template for an actual page-loading state / route-transition overlay — a fake "Loading {current_year}..." Win95 dialog with a progress bar that never finishes, as a tongue-in-cheek loading screen or 404/under-construction page.
